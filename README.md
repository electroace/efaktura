# eFaktura

Aplikacija za izradu faktura, ponuda i dokumenta s proizvoljnim nazivom. Korisnik vidi samo svoje dokumente. Besplatni paket omogućava 3 fakture mjesečno i do 5 stavki po fakturi; ponude i drugi dokumenti ne troše mjesečni limit. Korisnik može zatražiti plaćeni paket i odmah preuzeti PDF predračun BRATTS d.o.o. na jedan mjesec. Administrator dobija zahtjev u aplikaciji, email obavijest kada je Resend podešen, te nakon uplate aktivira pristup na jedan mjesec. Početna cijena je 22 KM mjesečno **s uključenim PDV-om** i može se pojedinačno promijeniti.

## Šta je potrebno za javno puštanje

GitHub čuva izvorni kod. Aplikaciju pokreće Cloudflare Worker, podaci su u Cloudflare D1, a logotipi u R2. Supabase Auth pruža prijavu putem emaila i lozinke te Google i Apple naloga. Za verifikacione emailove postavite Resend kao Supabase custom SMTP. Za email obavijesti o zahtjevima postavite Resend kao Worker tajnu. Nema integrisane kartične naplate; administrator uključuje plaćeni paket nakon evidentirane uplate.

1. Na povezanom Cloudflare računu već postoje D1 baza `efaktura-db` (`9747afff-b072-48ad-8164-06641a5e6da2`) i R2 bucket `efaktura-logos`. Worker `efaktura` je pripremljen s njihovim bindingom; javna adresa je isključena dok autentikacija i stvarni build nisu spremni.
2. Kreirajte Supabase projekat. U Auth uključite email potvrdu i Google. Apple uključite nakon podešavanja Apple Developer računa. Postavite Site URL na stvarnu adresu aplikacije i dodajte `https://VAŠA-ADRESA/auth/callback` na dozvoljene redirect URL-ove. Kopirajte project URL i publishable key. Supabase service role ključ se nikada ne unosi u browser ili GitHub.
3. Podesite Supabase custom SMTP preko Resenda i verifikovanog domena prije javne registracije. U Cloudflare Workeru dodajte tajnu `RESEND_API_KEY` i varijablu `MAIL_FROM` s potvrđenom adresom pošiljaoca. Ključ se ne dodaje u repozitorij. Zahtjev je uvijek vidljiv u administraciji, čak i ako email trenutno nije podešen ili slanje ne uspije. Na besplatnom Supabase ugrađenom SMTP-u nije predviđeno redovno slanje verifikacionih emailova.
4. GitHub repozitorij `electroace/efaktura` već je povezan s Cloudflareom kao repozitorij; na Workeru `efaktura` još treba uključiti **Settings → Builds → Connect**, izabrati taj repozitorij i automatski kreirati Cloudflare build API token. Build naredba: `pnpm install --frozen-lockfile && pnpm build`. Deploy naredba: `pnpm exec wrangler deploy --config dist/server/wrangler.json --keep-vars`. `--keep-vars` zadržava runtime varijable unesene u Cloudflare kontrolnoj ploči. D1 ID, naziv baze i bucket imaju podrazumijevane vrijednosti za ovaj račun u `vite.config.ts`; za drugi račun postavite build varijable `D1_DATABASE_ID`, `D1_DATABASE_NAME` i `R2_BUCKET_NAME`.
5. Runtime varijable u Cloudflare Workeru: `SUPABASE_URL` i `SUPABASE_PUBLISHABLE_KEY`; `APPLE_SIGN_IN_ENABLED=true` tek nakon uključivanja Apple providera. Dok nisu postavljene, javna prijava nije spremna. `electroace@gmail.com` je jedini administratorski email u trenutnoj verziji; registrujte taj potvrđeni email u Supabase Auth.
6. Migracije `0000`, `0001` i `0002` već su primijenjene na navedenu praznu D1 bazu (25. 9. 2026); potvrđene su tabele `companies`, `documents`, `billing_settings` i `plan_requests`. Na postojeću bazu ubuduće primjenjujte samo nove migracije, uz sigurnosnu kopiju prije promjena.
7. U administraciji unesite pune podatke BRATTS-a i račun za uplatu. Bez njih korisnici ne mogu izdati predračun. Testirajte registraciju, email potvrdu, Google prijavu, izolaciju dokumenata s dva naloga, tri fakture mjesečno, PDF predračun i aktivaciju nakon uplate. Apple prijavu testirajte tek kada imate Apple Developer članstvo. Tek tada povežite kupljenu domenu.

Lokalno: Node.js >=22.13, `pnpm install`, zatim `pnpm dev`. Lokalna D1 baza se priprema nakon builda pomoću Wranglerove `d1 execute --local` naredbe za svaku migraciju. Datoteka `.env.example` navodi potrebne varijable; stvarne vrijednosti držite izvan repozitorija.

## Sigurnost i granice

API provjerava prijavljenog korisnika na serveru kroz Supabase Auth, a upiti za dokumente filtriraju po njegovom identifikatoru. Ako Supabase nije podešen, pristup dokumentima je zatvoren. Admin pristup zahtijeva potvrđeni email `electroace@gmail.com`. PDF se dobija putem pregleda za štampu u browseru; Word kao `.docx`. Predračun nije fiskalni račun ni dokaz o plaćanju. Ovo nisu fiskalne/eRačun integracije niti automatsko izdavanje konačnog računa za pretplatu.
